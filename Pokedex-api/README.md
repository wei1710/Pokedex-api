# Pokedex API

Educational API developed for Software Quality subject at Erhvervsakademi København.
Focuses on software testing studies and quality assurance practices.

## Setup

Git clone the repository

`cd Pokedex-api`

`npm install`

## Development

`npm run dev`

## Database

`npm run db:reset`

## Test & Quality

`npm test`  
`npm run lint`  
`npm run lint:fix`  
`npm run format:check`  
`npm run format`
